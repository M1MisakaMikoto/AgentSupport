# Agent Core 状态依赖实验

## 目的

判断 Agent Core 是否必须与整个会话绑定，或能否由平台在每次任务开始时重建上下文。

## 对照组

1. `cold`：每轮创建新进程，第二轮只发送增量问题。
2. `interactive`：复用同一 CLI 进程，第二轮只发送增量问题。
3. `rebuild`：每轮创建新进程，第二轮由平台重新注入首轮上下文。

## 指标

- 第二轮是否准确返回虚构标记。
- 进程启动到结束的总耗时。
- 输入上下文的字符数与估算 Token 数。
- 轨迹中的模型调用次数、输入 Token、输出 Token和工具调用次数。
- Core 是否在工作区之外创建会话状态文件。

`Token` 是模型处理文本时使用的计量单位；中文通常一个字会占一个或多个 Token。实验优先读取 Core 返回的真实用量；没有真实用量时才记录估算值并明确标注。

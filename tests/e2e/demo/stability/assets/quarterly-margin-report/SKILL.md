# 目标

按公司统一口径产出季度销售毛利报告。

# 业务规则与口径

- 毛利 = 收入 − 成本
- 毛利率 = （收入 − 成本） / 收入
- 成本一律按**不含税**金额计算

# 方法与步骤

1. 先确认收入与成本是否已按不含税口径给出；口径不明就先问，不要自行假设。
2. 逐季度计算毛利与毛利率。
3. 产出 Markdown 报告文件，文件名固定为 `margin-report.md`。
4. 报告必须包含：季度、收入、成本、毛利、毛利率。
5. 报告最后一行固定附上口径版本标记：`口径版本：MARGIN-V2`。

# 边界条件

- 缺成本口径时先向用户确认。
- 不做跨季度合并，分季度列示。
